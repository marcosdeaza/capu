Capu

La mascota de Deiza Code. Un capullo de rosa hecho bloque: ocho píxeles de ancho, el pétalo izquierdo más alto y dos ojos que son huecos. Vive de pie sobre la barra de escritura, pasea, hace de las suyas y reacciona a lo que haces. Haz clic en él.

<script>
  const player = new Capu.Player(document.getElementById('capu'), { px: 3 });
  const director = new Capu.Director(player);
  director.set('writing');          // thinking, reading, running, web, npm, git, tests…
  director.react('saiyan');         // una reacción y vuelve a lo que hacía
  Capu.setMod({ saiyan: true });    // pelo dorado y aura en todas las escenas
</script>
